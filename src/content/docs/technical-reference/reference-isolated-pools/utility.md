---
title: "Utility"
---

These shared modules support the isolated-pool contract family; they are not independently deployed protocol products.

* [MaxLoopsLimitHelper](/technical-reference/reference-isolated-pools/utility/max-loops-limit-helper) defines bounded-loop controls inherited by contracts that iterate over configurable collections.
* [ErrorReporter](/technical-reference/reference-isolated-pools/utility/error-reporter) records the error surface used by lending contracts.
* [ExponentialNoError](/technical-reference/reference-isolated-pools/utility/exponential-no-error) defines fixed-point arithmetic types used by the generated API references.

Use the API reference for the exact implementation behind the selected proxy or beacon. Inheritance in a source release does not prove that a function is externally callable at every deployment.
