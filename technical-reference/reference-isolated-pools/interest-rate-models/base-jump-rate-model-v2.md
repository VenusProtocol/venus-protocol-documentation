# BaseJumpRateModelV2 (legacy page)

`BaseJumpRateModelV2` is not a separate contract in the current `isolated-pools` source. Its old documentation split the live `JumpRateModelV2` ABI across two pages and used block-only language that is wrong on time-based networks.

Use the consolidated [`JumpRateModelV2` reference](jump-rate-model-v2.md) for the v4.4.0 source family. Before applying it to an older deployment, identify the exact model bytecode and constructor arguments onchain; the continued existence of this URL is not evidence that a historical base-contract deployment is active.
