# Utility modules

These shared modules support the isolated-pool contract family; they are not independently deployed protocol products.

* [MaxLoopsLimitHelper](max-loops-limit-helper.md) defines bounded-loop controls inherited by contracts that iterate over configurable collections.
* [ErrorReporter](error-reporter.md) records the error surface used by lending contracts.
* [ExponentialNoError](exponential-no-error.md) defines fixed-point arithmetic types used by the generated API references.

Use the API reference for the exact implementation behind the selected proxy or beacon. Inheritance in a source release does not prove that a function is externally callable at every deployment.
